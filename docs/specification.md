# Введение

Название языка: Python++.
Наш язык является смесью С++ и Python.
Целью такого решения является желание сохранить удобство написания кода и скорость работы языка.

Связь со спецификацией C++ и Python:
Некоторые части программы используют спецификацию С++, такие, как:
- объявление переменных;
- создание структур;
- объявление функций.
А некоторые - спецификацию Python, например:
- циклы;
- условия.

Область видимости формируется с помощью "{}" (как в C++).
Табуляция не влияет на область видимости.

Система типов:
Поддерживаются следующие типы:
    - `int` (32-битное число);
    - `bool` (булевое значение);
    - `string` (строковый тип);
    - пользовательские структуры с атрибутами;
    - `void` - специальный тип для пометки функций, не возвращающих значение.

## Лексика

1. Идентификатор - это последовательность букв английского алфавита, цифр и символов подчёркивания "_", которая начинается с буквы или символа подчеркивания.
2. Ключевые слова — это последовательности букв, зарезервированные для однозначности синтаксических правил, они не являются идентификаторами.
3. Регистр идентификаторов и ключевых слов имеет значение.
4. Литералы целых чисел — это последовательность десятичных цифр:
    - Литерал не может начинаться с 0, если он содержит более одной цифры;
    - Литералы не содержат знак и всегда обозначают положительные числа;
    - Не допускаются литералы целых чисел, значение которых не попадает в диапазон 32-битных целых положительных чисел(максимальное допустимое значение: 2147483647).
    - Если после цифр целочисленного литерала сразу следует символ, допустимый в идентификаторе (буква или "_"), это считается лексической ошибкой (например, `123abc` или `1_var`).
5. Строковые литералы заключаются в двойные кавычки `"`.
    - Внутри строки допускаются любые символы, кроме неэкранированной двойной кавычки и фактического символа переноса строки (LF/CR).
    - Для представления специальных символов используются escape-последовательности: `\"` (двойная кавычка), `\\` (обратный слеш), `\n` (перенос строки), `\r` (возврат каретки), `\t` (горизонтальная табуляция), `\f` (перевод страницы).
    - Допустимым пустой строковый литерал `""`.
    - Наличие неизвестной escape-последовательности (например, `\q`) или незакрытый строковый литерал являются лексической ошибкой.
6. Комментарии и пробельные символы могут появляться между токенами и игнорируются при разборе.
7. Комментарии начинаются с `/*` и заканчиваются на `*/`, вложенные комментарии не допускаются.

Список пробельных символов:

| Символ                        | Код ASCII |
| ----------------------------- | --------- |
| Пробел  (SP)                  | 0x20      |
| Горизонтальная табуляция (HT) | 0x9       |
| Перенос строки (LF)           | 0x0A      |
| Возврат каретки (CR)          | 0x0D      |
| Form feed (FF)                | 0x0C      |

Список ключевых слов: `bool`, `int`, `string`, `void`, `null`, `struct`, `true`, `false`, `if`, `else`, `elif`, `while`, `exception`.

Список лексем, используемых в роли операторов выражения: `=`, `==`, `!=`, `<`, `>`, `<=`, `>=`, `&&`, `||`, `!`, `+`, `-`, `*`, `/`, `.`, `++`, `--`

Список прочих лексем: `[`, `]`, `(`, `)`, `{`, `}`, `,`, `;`
