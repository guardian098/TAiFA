# Спецификация языка Python++

## Введение

Python++ — язык программирования, который сочетает некоторые особенности C++ и Python. Программа целиком располагается в одном файле и начинается с функции `void main()`. Язык поддерживает целочисленные арифметические выражения и вывод чисел.

Область видимости задаётся фигурными скобками `{}`, как в C++. Отступы и переводы строк на структуру программы не влияют.

## Лексика

Лексические правила определяют, как исходный текст разбивается на токены. Неизвестный символ в тексте программы является лексической ошибкой.

### Идентификаторы

Идентификатор — последовательность английских букв, цифр и символов подчёркивания `_`, которая начинается с буквы или символа подчёркивания. Регистр имеет значение.

Имена `main`, `print`, `sqrt`, `abs`, `min`, `max` лексически являются идентификаторами. Особый смысл им придаёт грамматика.

### Ключевые слова

Ключевые слова: `bool`, `int`, `string`, `void`, `null`, `struct`, `true`, `false`, `if`, `else`, `elif`, `while`, `exception`.

Ключевые слова не являются идентификаторами, их регистр имеет значение. Ключевые слова, определённые в лексике, не обязательно используются в текущей версии грамматики: сейчас применяются только `void` и `int`.

### Целочисленные литералы

Целочисленный литерал — последовательность десятичных цифр без знака. Литерал не может начинаться с `0`, если содержит более одной цифры. Допустимый диапазон: от `0` до `2147483647`; литерал вне диапазона является лексической ошибкой.

Если сразу после цифр следует буква или `_`, это лексическая ошибка. Например, `123abc` и `1_var` недопустимы. Знак числа задаётся отдельным унарным оператором.

### Строковые литералы

Строковые литералы заключаются в двойные кавычки `"`. Внутри строки допускаются любые символы, кроме неэкранированной двойной кавычки и фактического переноса строки (LF/CR).

Поддерживаются escape-последовательности:

| Последовательность | Значение |
| --- | --- |
| `\"` | двойная кавычка |
| `\\` | обратная косая черта |
| `\n` | перевод строки |
| `\r` | возврат каретки |
| `\t` | горизонтальная табуляция |
| `\f` | перевод страницы |

Пустая строка `""` допустима. Неизвестная escape-последовательность и незакрытый строковый литерал являются лексическими ошибками.

В текущей версии строковые литералы в грамматике не используются.

### Пробельные символы

| Символ | Код ASCII |
| --- | --- |
| Пробел (SP) | `0x20` |
| Горизонтальная табуляция (HT) | `0x09` |
| Перенос строки (LF) | `0x0A` |
| Возврат каретки (CR) | `0x0D` |
| Form feed (FF) | `0x0C` |

### Комментарии

Блочный комментарий начинается с `/*` и заканчивается на ближайшее `*/`. Вложенные комментарии не поддерживаются. Незакрытый комментарий является лексической ошибкой.

Пробельные символы и комментарии могут находиться между токенами и игнорируются при разборе.

### Операторы и разделители

| Категория | Лексемы |
| --- | --- |
| Арифметические | `+`, `-`, `*`, `/`, `%` |
| Сравнения | `==`, `!=`, `<`, `>`, `<=`, `>=` |
| Логические | `&&`, `||`, `!` |
| Прочие | `=`, `.`, `++`, `--` |

Разделители: `[`, `]`, `(`, `)`, `{`, `}`, `,`, `;`.

В текущей грамматике используются арифметические операторы и разделители `(`, `)`, `{`, `}`, `,`, `;`. Остальные лексемы определены, но пока не применяются.

`++` и `--` распознаются как единые лексемы. Чтобы записать два унарных знака подряд, их разделяют пробелом или скобками: `- -5`, `-(-5)`.

## Синтаксис

Грамматика описывает структуру программы и выражений. Терминалы, ключевые слова и токены описаны в разделе «Лексика»; `integer_literal` обозначает токен целочисленного литерала.

### EBNF-грамматика

```ebnf
program = main_function ;

main_function = "void", "main", "(", ")", block ;

block = "{", { statement }, "}" ;

statement = print_statement | expression_statement ;

print_statement = "print", "(", expression, ")", ";" ;

expression_statement = expression, ";" ;

expression = additive_expression ;

additive_expression = multiplicative_expression,
    { ( "+" | "-" ), multiplicative_expression } ;

multiplicative_expression = unary_expression,
    { ( "*" | "/" | "%" ), unary_expression } ;

unary_expression = { "+" | "-" }, primary_expression ;

primary_expression = integer_literal
    | "(", expression, ")"
    | sqrt_call
    | abs_call
    | min_call
    | max_call ;

sqrt_call = "sqrt", "(", expression, ")" ;

abs_call = "abs", "(", expression, ")" ;

min_call = "min", "(", expression, ",", expression, ")" ;

max_call = "max", "(", expression, ",", expression, ")" ;
```

### Приоритет и ассоциативность операторов

Операторы с более высоким приоритетом выполняются раньше.

| Приоритет | Операторы | Операция | Ассоциативность |
| --- | --- | --- | --- |
| 1 (высший) | унарные `+`, `-` | указание знака числа | правая |
| 2 | `*`, `/`, `%` | умножение, целочисленное деление, остаток от деления | левая |
| 3 (низший) | `+`, `-` | сложение, вычитание | левая |

Например, `2 + 3 * 4` вычисляется как `2 + (3 * 4)`, а `10 - 4 - 1` — как `(10 - 4) - 1`. Скобки задают порядок явно: `(2 + 3) * 4`.

## Основные правила выполнения

- Инструкции внутри `main` выполняются последовательно.
- `print(expression);` вычисляет выражение и выводит его целочисленное значение в стандартный поток вывода с переводом строки.
- Инструкция-выражение вычисляется, но результат не выводится.
- Все значения выражений имеют тип `int` (32-битное знаковое целое). Переполнение является ошибкой выполнения.
- `/` — целочисленное деление с отбрасыванием дробной части.
- `%` — остаток от целочисленного деления. Знак результата совпадает со знаком делимого, так что `a == (a / b) * b + a % b`. Деление и взятие остатка на ноль являются ошибками выполнения.
- `abs(x)` — абсолютное значение `x`.
- `sqrt(x)` — целая часть квадратного корня из `x`. Отрицательный аргумент является ошибкой выполнения.
- `min(a, b)` и `max(a, b)` — меньшее и большее из двух чисел.

## Пример программы

```cpp
void main() {
    print(7 / 2);
    print(7 % 2);
    print(abs(-5));
    print(sqrt(16));
    print(min(3, 5));
    print(max(3, 5));
}
```

Вывод программы:

```text
3
1
5
4
3
5
```
