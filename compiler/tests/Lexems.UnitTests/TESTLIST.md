# Список тестов

## Идентификаторы и ключевые слова
- [] Ключевые слова как токены: `bool int string void`
- [] Ключевые слова как префиксы идентификаторов: `intx integer ifelse`
- [] Регистр для идентификаторов: `Int IF While TRUE Null`
- [] Разбор идентификаторов: `x _var count123 camelCase snake_case`
- [] `int x = 10; bool flag = true` — int, bool, true
- [] `while counter != 3 {counter++}` - while
- [] `struct Point {int x; string s;}` — struct, string
- [] `if n == 0 {n = 1} elif n == 1 {} else {n = 2}` — if, elif, else
- [] `void foo(){}` - void
- [] `if a=null{}` - if, null

## Литералы
- [] Разбор литералов целых чисел: `0 1234 56780 12034 1010 1200`
- [] Граница диапазона: `2147483647`; переполнение (ошибка): `2147483648`
- [] Разбор строк: `"" "0" "Hello, world!"`
- [] Цифры, склеенные с идентификатором (ошибка): `123abc 1_var`
- [] Разбор escape-последовательностей: `"\"\\\n\r\t\f" "Hello\tWorld\n"`
- [] Неизвестная escape-последовательность (ошибка): `"\q"`
- [] Незакрытые строки (ошибка): `"открытая строка без конца`
- [] Ведущие нули у целых чисел(ошибка)  `000233 01 00`

## Операторы, разделители и скобки
- [] `x + y / (10 - z * 2)` — операторы `+ - * /`, скобки `()`
- [] `a == b != c || !d` — операторы `==`, `!=`, `||`, `!`
- [] `a <= b && b >= c && a < c > d` — операторы `<=`, `>=`, `&&`, `<`, `>`
- [] `speed.x = v[0]` — операторы `.`, `=`, скобки `[]`
- [] `i++; j--` — операторы `++`, `--`, разделитель `;`
- [] Максимально длинный токен: `a===b` — `==`, `=`; `a+++b` — `++`, `+`
- [] `foo(x, y); {1, 2}` — скобки `{}`, разделитель `,`
- [] Одиночные `&` и `|` (ошибка): `a & b`, `a | b`

## Пробелы и комментарии

- [] Пропуск пробельных символов: `' '`, `'\t'`, `'\r'`, `'\n'`, `'\f'`
- [] Комментарии: `/* ... */`
- [] Комментарий, склеенный с кодом: `int/*коммент*/x=5`;
- [] Вложенные комментарии не допускаются: `/* a /* b */ c */` — c, `*`, `/`
- [] Незакрытый комментарий (ошибка): `/* abc`
