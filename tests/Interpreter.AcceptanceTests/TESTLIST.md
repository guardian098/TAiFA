# Список тестов


## Выполнение программ (в процессе, через `StringReader` и `StringWriter`)
- [] Пустая программа: `void main() { }` — вывод пустой
- [] Вывод числа: `print(42);` — output: `42\n`
- [] Несколько инструкций подряд: `print(1); print(2);` — output: `1\n2\n`
- [] Выражение-инструкция ничего не выводит: `7 + 3;`
- [] Арифметика и приоритеты: `print(10 + 2 * 5);` — output: `20\n`
- [] Скобки, унарные операторы и `%`: `print(-(5 + 3)); print(17 % 5);` — output: `-8\n2\n`
- [] Встроенные функции: `print(min(sqrt(16), abs(-5)));` — output: `4\n`
- [] Выражение из спецификации с результатом `80`
- [] Комментарии и произвольные пробельные символы в исходном коде


## Ввод `readInt()`
- [] Одно число: `print(readInt());`, ввод `7` — output: `7\n`
- [] Сумма двух чисел: `print(readInt() + readInt());`, ввод `2 3` — output: `5\n`
- [] Числа в разных строках и с лишними пробелами: ввод `  2 \n\n 3 `
- [] Отрицательное число во вводе: ввод `-4`
- [] Пример из спецификации: ввод `17 5 3 9` — output: `22\n9\n`
- [] Конец ввода (ошибка): `print(readInt());`, пустой ввод — `Unexpected end of input.`
- [] Недостаточно чисел (ошибка): `readInt() + readInt()`, ввод `2`
- [] Некорректное число (ошибка): ввод `2 x` — `Invalid integer input 'x'.`


## Ошибки времени выполнения (в процессе)
- [] Деление на ноль: `print(1 / 0);`
- [] Остаток от деления на ноль: `print(1 % 0);`
- [] Переполнение при сложении и умножении
- [] Корень из отрицательного числа: `print(sqrt(-1));`
- [] Вывод до ошибки сохраняется: `print(1); print(1 / 0);` — в output остаётся `1\n`


## Запуск интерпретатора отдельным процессом (`interpreter <файл>`)
- [] Корректная программа: stdout содержит результат, код возврата `0`, stderr пуст
- [] Ввод из stdin: `print(readInt() + readInt());`, stdin `2 3` — stdout `5`, код `0`
- [] Лексическая ошибка: stderr содержит `Lexical error`, код `1`, stdout пуст
- [] Синтаксическая ошибка: stderr содержит `Syntax error`, код `1`, stdout пуст
- [] Ошибка времени выполнения: stderr содержит `Runtime error`, код `1`
- [] Вывод до ошибки времени выполнения остаётся в stdout: `print(1); print(1 / 0);`
- [] Конец stdin (ошибка): stderr содержит `Runtime error`, код `1`
- [] Некорректное число в stdin (ошибка): stderr содержит `Runtime error`, код `1`
- [] Запуск без аргументов: stderr содержит `Usage`, код `1`
- [] Несуществующий файл: stderr содержит `not found`, код `1`
