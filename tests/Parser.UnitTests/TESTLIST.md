# Список тестов

## Точка входа и структура программы
- [] Корректная пустая программа: `void main() { }`
- [] Пропуск void(ошибка): `main() {}`
- [] Отсутствие закрывающей `}`(ошибка): `void main() { print(1);` 
- [] Отсутствие открывающей `{` (ошибка): `void main() print(1);` 
- [] Неверный тип возврата (ошибка): `int main() { }`
- [] Мусор после main (ошибка): `void main() { } void main() { }`
- [] Мусор после main (ошибка): `void main() { } extra`

## Операторы
- [] print с числом: `print(42);`
- [] print с выражением: `print(2 + 3);`
- [] Отсутствие `;` после `print` (ошибка): `print(1)`
- [] Отсутствие `(` у `print` (ошибка): `print 1);`
- [] Отсутствие `)` у `print` (ошибка): `print(1;`
- [] Пустой print (ошибка): `print();`
- [] Выражение-инструкция: `7 + 3;`
- [] Несколько инструкций подряд: `print(1); print(2);`

## Арифметические выражения
- [] Сложение: `1 + 2`
- [] Вычитание: `5 - 3`
- [] Умножение: `3 * 4`
- [] Деление: `20 / 5`
- [] Остаток: `17 % 5`
- [] Приоритет `*` над `+`: `10 + 2 * 5`
- [] Скобки переопределяют приоритет: `(10 + 2) * 5`
- [] Левая ассоциативность -: `10 - 3 - 2`
- [] Левая ассоциативность /: `100 / 10 / 2`
- [] Смешанные операторы: `1 + 2 * 3 - 4 / 2`

## Унарные операторы (Парсер)
- [] Унарный минус: `-5`
- [] Унарный плюс (no-op): `+5`
- [] Двойной минус через пробел: `- -5`
- [] Двойной минус в скобках: `-(-5)`
- [] Унарный минус в выражении: `-(5 + 3)`
- [] Унарный минус перед функцией: `-sqrt(16)`

## Встроенные функции

- [] `sqrt(16)` — один аргумент
- [] `abs(-5)` — один аргумент
- [] `min(3, 5)` — два аргумента через запятую
- [] `max(3, 5)` — два аргумента через запятую
- [] Вложенные вызовы: `min(sqrt(16), abs(-5))`
- [] Функция как часть выражения: `sqrt(16) + 1`
- [] Отсутствие `(` у функции (ошибка): `sqrt 16)`
- [] Отсутствие `,` в min (ошибка): `min(3 5)`
